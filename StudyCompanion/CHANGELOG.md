## v1.9 —— 把资源文件收进 `assets\` 文件夹

`StudyCompanion\` 顶层原来散着一堆图片和图标，现在统一收进 **`assets\`**：

```
assets\
├─ app.ico                程序图标（多尺寸，编译时内嵌进 exe）
├─ icon-preview.png       图标各尺寸预览
├─ screenshot.png         主界面截图
├─ screenshot-toast.png   右下角提示窗截图
├─ screenshot-menu.png    配套资源下拉菜单截图
└─ screenshot-doc.png     更新日志阅读器截图
```

顶层现在只剩：`StudyCompanion.exe`、`README.md`、`CHANGELOG.md`、`build.ps1`、`settings.ini` 和 `assets\ src\ data\ tools\` 四个文件夹。

同步改的地方：

- `build.ps1` 里图标路径改为 `assets\app.ico`
- `tools\make_icon.py` 改为按脚本自身位置推算目录（不再写死绝对路径），输出到 `assets\app.ico` 与 `assets\icon-preview.png`
- `README.md` 里的图片引用改为 `assets/...`，目录结构说明同步更新

### 另一个小修复

`build.ps1` 之前靠 UTF-8 BOM 才能让 PowerShell 5.1 正确读中文，但**只要用编辑器改一次就会掉 BOM，脚本立刻语法报错**（这次就中招了）。
现在把脚本内容全部改成**纯 ASCII（英文提示）**，彻底不依赖 BOM。

## v1.8 —— 换掉 exe 图标；「关闭到托盘」提示窗改成 3 秒倒计时

### 1. 提示窗（关闭窗口后右下角那个）

- **删掉了「开始学习」按钮** —— 窗口都已经最小化了，这个按钮没意义
- **3 秒后自动消失**（原来 40 秒）
- 唯一的「知道了」按钮上直接显示倒计时：**知道了（3）→（2）→（1）**，到 0 自动关闭
- 弹窗高度从 168 压到 146，去掉多余留白（单行说明不需要那么高）
- 按钮宽度按「知道了（88）」预留，数字变化时不会左右抖动

> 提醒浮窗（到学习时间弹的那个）保持不变，仍然是「开始学习 / 知道了」两个按钮、120 秒。

### 2. 程序图标

原来用的是程序里现画的「学」字方块，确实不好看。现在换成**多尺寸 .ico**：

- 蓝色渐变圆角方 + 白色日历页 + 蓝色对勾
- 一次性生成 **16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256** 十个尺寸
- 小尺寸单独渲染（6 倍超采样后缩放），不是把 256 直接缩小，所以 16px 也不糊

实现方式：

- `tools\make_icon.py` 生成 `app.ico`（纯 Pillow 绘制，不依赖外部素材）
- 编译时加 `/win32icon:app.ico` —— **这样资源管理器里才能看到 exe 图标**
- 同时加 `/resource:app.ico,StudyCompanion.app.ico` —— 程序运行时按需要的尺寸取用（托盘要 16px、标题栏要 32px），比让系统缩放 32px 更清晰

`AppIcon.Get(size)` 的取值顺序：内嵌资源 → `ExtractAssociatedIcon` → 程序化兜底绘制。

**注意**：Windows 会缓存图标。如果资源管理器里还显示旧图标，按 `F5` 刷新，或者把 exe 改名/移动一下再改回来；实在不行清一下图标缓存（`ie4uinit.exe -show`）。

### 3. 顺带修复

`build.ps1` 存成了无 BOM 的 UTF-8，PowerShell 5.1 会按 ANSI 解码，脚本里的中文会让语法直接报错。已加上 UTF-8 BOM。

## v1.7 —— 修复「点 X 后任务栏图标消失、窗口却还留在屏幕上」

### 原因

关闭逻辑写在 `FormClosing` 里，而且顺序是 `Hide()` → `ShowInTaskbar = false`。这里有两个坑：

1. **在 `FormClosing` 里直接 `Hide()` 不可靠。**
   设了 `e.Cancel = true` 之后，关闭流程**还会继续走完**，它会按自己的逻辑重新应用窗口状态，把刚隐藏的窗口又显示出来。
   正确做法是用 `BeginInvoke` 把隐藏动作**推迟到关闭流程结束之后**再执行。

2. **`ShowInTaskbar` 的赋值会销毁并重建窗口句柄。**
   在已经 `Hide()` 之后改它，重建出来的新窗口可能带上可见状态。
   所以必须**先设 `ShowInTaskbar`、后 `Hide()`**。

这两件事合起来正好就是看到的现象：任务栏图标没了（`ShowInTaskbar = false` 生效了），窗口却还在屏幕上。

### 改法

- 关闭动作改成 `e.Cancel = true` + `BeginInvoke(HideToTray)`，把隐藏推迟到关闭流程之后
- `HideToTray()` 里固定顺序：**先** `ShowInTaskbar = false`，**再** `Hide()`，最后补一次 `Visible = false` 兜底
- 恢复显示时同样把 `ShowInTaskbar = true` 放在 `Show()` 之前

### 顺带新增：关闭按钮行为可选

「设置与工具 → 启动与关闭」新增一个开关：

- **关闭时：最小化到托盘**（默认）—— 点 X 后隐藏到右下角托盘，继续到点提醒
- **关闭时：直接退出** —— 点 X 就真正结束程序

选「直接退出」时，程序会走完整退出流程（停掉提醒定时器、移除托盘图标、结束进程），不会留下后台进程。

### 顺带修的托盘退出逻辑

- 主窗口被真正关闭时，`ApplicationContext` 现在会**自动结束整个程序**（之前窗口关了、进程还赖着不走）
- `Quit()` 加了 `_quitting` 标志，避免「托盘退出 → 关闭窗口 → 又触发退出」的重复调用

### 自检

新增 `StudyCompanion.exe --closetest`：离屏建窗口，用两条关闭路径验证最终状态，输出 `closetest.txt`。

```
【场景 1】设置 = 最小化到托盘
  窗体 Visible      = False    期望 False      ✔
  ShowInTaskbar     = False    期望 False      ✔
  系统认为窗口可见  = False    期望 False      ✔
  窗体已销毁        = False    期望 False      ✔（进程要留着提醒）

【场景 2】设置 = 直接退出
  窗体已销毁        = True     期望 True       ✔
  系统认为窗口可见  = False    期望 False      ✔
```

> 说明：这个离屏测试能验证「隐藏 / 退出」的最终状态，但**验证不了屏幕上的实际观感**（测试时窗口在屏幕外、且没有真实消息循环）。本次修复主要依据的是 WinForms 的标准写法：`BeginInvoke` 推迟隐藏 + 先设 `ShowInTaskbar` 后 `Hide`。

## v1.1 —— 修复「点击日历导致界面抖动」

抖动是布局死循环造成的，三个根因都已修掉：

1. **列宽依赖滚动条**：原来列宽按 `ClientSize.Width` 计算，而竖向滚动条出现/消失会改变它 → 宽度变 → 卡片文字换行数变 → 卡片高度变 → 滚动条又切换 → 面板 `Resize` 再次触发布局，来回振荡。
   现在列宽一律按「面板宽度 − 预留滚动条宽度」计算，与滚动条状态无关，布局一次收敛。
2. **没有重入保护**：`Resize` 在布局过程中被再次触发会递归刷新。现在加了 `_busy` 重入锁，内部布局走不设锁的 `DoLayoutLeft / DoLayoutRight`。
3. **重建控件导致闪动**：原来切换日期会销毁并重建整列卡片，点「标记完成」也会整列重建。现在
   - 重建前用 `WM_SETREDRAW` 冻结重绘，完成后再一次性刷新
   - 点击**同一天**不再触发任何刷新
   - 打卡只做轻量刷新（`RefreshLight`），不重建控件
   - 修掉了「遍历 `Controls` 的同时 `Dispose`」的隐患

另外修掉了日历控件同时用 `Dock = Top` 又手动 `SetBounds` 造成的定位冲突，以及每次布局都重复挂载 `Paint` 事件的无用操作。

自检命令 `StudyCompanion.exe --layouttest` 可复现验证。

## v1.0 —— 首个版本

按需求实现的基础功能：

- **开机自启**：写入注册表 `HKCU\...\CurrentVersion\Run`（参数 `--tray`），启动后静默驻留右下角托盘
- **读取 Schedule.xlsx**：自己解析 xlsx（zip + XML），不需要安装 Excel；按当天日期显示时间段、科目、小节、页码、练习范围
- **配套视频超链接**：按当天小节自动匹配精确资源 + YouTube 搜索 + Bilibili 搜索（免翻墙）
- **打开课本 PDF**：直接跳到该小节所在的 PDF 页（`#page=` 锚点）
- **到点提醒**：时段开始时右下角滑出浮窗 + 托盘气泡 + 提示音；结束前 5 分钟再提醒一次；开机时若正在时段中会提示「正在进行 + 剩余分钟」
- **完成打卡**：点「标记完成」，卡片变绿、日历打钩、进度条前进；记录写入 `data\progress.tsv`，重启不丢
- **内置日历与统计**：可翻月回看任意一天；本周进度、累计学时、连续打卡、本月全勤
- **导出学习记录 CSV**
- 支持课表被 WPS 占用时使用缓存兜底
