# Q2 — Durham University（durham.ac.uk, QS 2027 #85）工程类专业的 NCUK IFY 入学要求

> 调查时间：本次会话（2026 申请季资料）
> 学生背景（既定事实，未复核）：NCUK IFY 三学术模块 = Technical Maths / Further Mathematics / Physics，另有学术英语 EAP。NCUK 等级→UCAS 分数：A\*=56, A=48, B=40, C=32, D=24。学生上限 **BBB (120) ~ ABB (128)**；AAB (136)、AAA (144) 不可及。目标：电子电气工程（EEE）优先，其次机械/土木/航空/材料。全程英国就读。不能学化学。不考虑商科。
> 本文件范围：Durham 工程类（排除 Computer Science 与 Electronic/Electrical Engineering）的 IFY 要求；并核验中介关于「Durham 工程要求 AAA 且不接受 NCUK EAP 替代雅思（雅思 6.5，单项 6.0）」的说法。

---

## 一、结论（直接回答任务问题）

**未发现 Durham 存在任何「ABB 或更低」的工程类入学门。** 依据：

1. **官方可读证据只确认了一件事**：Durham 是 NCUK 成员校，**接受 NCUK International Foundation Year** 作为入学资格（NCUK 官方合作院校页，官方）。但该页**没有给出任何分数/等级**。
2. **所有出现的分数都高于学生上限**：
   - 中介（新东方前途出国，引 NCUK 2026-27 宣传册）称 Durham 工程方向 IFY 要求 **AAA**（并点名化学工程、土木工程 = AAA）；商科方向 AAB。
   - 中介（UNILINK）与 UCAS 数据镜像（UniversityDB）一致给出 Durham 工程本科 A-level 典型录取 **A\*AA**（Mechanical、Civil 均如此）。
   - IFY AAA = 144 UCAS 分，AAB = 136 分，**均高于学生上限 128（ABB）**。因此即使「AAB 的 Biomedical Engineering」那些行确属 Durham，学生也达不到。
3. **官方分数表全部无法读取**：Durham 官网整域对本次抓取返回 CloudFront 403；NCUK 官方 Course Finder 行数据由 JS 注入；NCUK 权威分数线表是 PDF（本环境不可读，需人工下载）；NCUK 宣传册的 FlipHTML5 托管页整站 Cloudflare 403。因此**上述任何数字都没有得到官方一手确认**——按规则只能标注为中介 / 官方文件快照（归属未确认），不能当作 Durham 官方要求断言。
4. **EAP 问题（重点）**：**未查到 Durham 官方关于 NCUK EAP 的声明**（最可能载有该声明的 Durham 官方页面 `Other English Language Qualifications` 被 403 阻断）。仅有中介明确称「杜伦大学不认可 EAP 成绩替代雅思」，要求雅思总分 6.5 且单项不低于 6.0；且另一篇中介汇总「英国方向认可 EAP 的成员校」时列出 Manchester / Bristol / Birmingham / Leeds / Sheffield / QMUL，**独独没有 Durham**——与「Durham 不接受 EAP」的说法方向一致，但证据等级仍为**中介**，非官方。

**一句话**：Durham 对 NCUK IFY 是开放的，但工程方向的门槛看起来在 **AAA（IFY）/ A\*AA–AAA（A-level）**，**没有 ABB 及以下的口子**；学生的 ABB(128) 上限很可能不够，电子电气（本就排除在本次范围外）在 Durham 同样属于高门槛方向。若仍要冲 Durham，语言是第二道门槛（中介称 EAP 不被接受，须雅思 6.5/6.0）。
